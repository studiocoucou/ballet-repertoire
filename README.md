# バレーレペトワ

2025年のオープニング映像をスマートフォンで視聴するためのページです。

- `index.html`：音声付き動画の再生ページ
- `opening.mp4`：公開用動画（1分49秒・1920×1080）
- `poster.jpg`：再生前の静止画
- `.nojekyll`：静的ファイルをそのまま配信するための設定

GitHub Pagesの公開元は `main` ブランチの `/ (root)` です。
ページURLを維持して `opening.mp4` を差し替えれば、印刷済みのQRコードを引き続き使用できます。

検索エンジンへの掲載を控える `noindex` を設定しています。閲覧制限ではないため、URLを知っている人は視聴できます。
